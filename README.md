# Agent Rulebook

A working draft of a rulebook for humanizing AI agents, drawn from running a real agent org. Docs are built with VitePress.

## Local development

```bash
npm install
npm run docs:dev
```

Build and preview:

```bash
npm run docs:build
npm run docs:preview
```

## Publishing

This repository is private. Publishing the site or attaching a custom domain requires explicit owner approval.
